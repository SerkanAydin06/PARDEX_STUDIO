# PARDEX Studio

Yapay zekâların departmanlar hâlinde çalıştığı yerel yazılım şirketi. Patron hedefi verir ve onaylar; ekip planlar, yazar, denetler, düzeltir ve hazır ürünü teslim eder. Claude, ChatGPT (Codex) ve Gemini aboneliklerini en az kota harcayacak şekilde kullanır.

## Başlangıç (Windows)

1. Python 3.10+ ve [Git](https://git-scm.com/downloads/win) kur.
2. `02_AI_CLI_KUR.cmd` ile Claude Code, Codex CLI ve Gemini CLI'ı kur; her birine kendi hesabınla giriş yap. Bağımsız kod kontrolü için **en az iki farklı AI** gerekir.
3. `09_SIRKET_PANELI.cmd` dosyasına çift tıkla. Tarayıcıda **Patron Ofisi** açılır.
4. **Projeler → Yeni proje**: Ürün Müdürüyle ana hatları konuş, "Bunu yap" de.

Ürünler bu deponun dışında, kendi klasörlerinde ve kendi git depolarında tutulur. Sistem hesap açmaz, ödeme yapmaz, yayın yapmaz.
