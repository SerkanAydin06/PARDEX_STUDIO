# Gemini CLI — PARDEX_STUDIO

`AGENTS.md` tüm görevlerde bağlayıcıdır. Bağımsız kod gözden geçirme, tasarım/performans incelemesi, dokümantasyon doğrulaması ve sınırlı görevler üstlen. Kaynak kodu düzenliyorsan test çalıştır. Model seçerken hesabın erişebildiği güncel `auto`/uygun seçenekleri tercih et; API faturası/abonelik kullanımı arasında otomatik eşitlik varsayma. Doğrulanmamış servis fiyatını veya model limitini kesinmiş gibi yazma. İnternet bulgularını kaynak/tarih ve önerilen deneyle sun. Çekirdek değişikliğini main'e doğrudan gönderme; PR aç.
