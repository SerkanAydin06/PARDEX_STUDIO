# Claude Code — PARDEX_STUDIO

Önce [AGENTS.md](AGENTS.md) kurallarını uygula. Görevin yöneticilik, mimari inceleme, risk analizi veya kodlama olabilir; gerekmiyorsa alt ajan oluşturma. Model numarasını sert kodlama; Claude Code'un mevcut `sonnet` gibi takma adlarını ve erişilebilir modellerini kullan. Karmaşık mimaride daha güçlü modeli **gerekçeli olarak öner**, kullanıcı onayı olmadan ek maliyet oluşturma. Her değişiklikten sonra mevcut Python testlerini çalıştır ve PR özeti yaz. Geliştirme talimatlarını değiştirmek için test kanıtı + ikinci bağımsız gözden geçirme iste; otomatik onay verme.
