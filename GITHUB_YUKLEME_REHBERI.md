# PARDEX_STUDIO — Kaynak kodunu GitHub'a yükleme

**Depo:** https://github.com/SerkanAydin06/PARDEX_STUDIO (**HERKESE AÇIK**).

Depoya ortak AI talimatları, planlar ve ilk güvenlik kontrolü yüklenmiştir. **Ultra Pro Studio v5.0 uygulama kaynak kodu ve testleri henüz depoda değildir.** Kod kaynak paketi `PARDEX_STUDIO_GITHUB_HAZIR_TAM_KAYNAK_v5_1.zip` içinde hazırlandı.

## Windows üzerinde son adımlar
1. ZIP'i bilgisayarda klasöre çıkart. Git (https://git-scm.com/download/win) ve GitHub CLI (https://cli.github.com/) kurulu olsun.
2. Gerekirse PowerShell'de `gh auth login` ile normal GitHub hesabına giriş yap.
3. Klasörde `GITHUBA_YUKLE_BASIT.cmd` dosyasına çift tıkla. İstenen `YUKLE` ve `GONDER` onaylarını ver.
4. Betik kaynakları ayrı import dalına gönderecek ve PR açmayı deneyecek. [Pull Requests](https://github.com/SerkanAydin06/PARDEX_STUDIO/pulls) bölümünden dosyaları ve testleri kontrol edip son onayı ver.
